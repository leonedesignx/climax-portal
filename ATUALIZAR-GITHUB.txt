1) Abra a pasta do SEU REPOSITORIO que já tem a pasta .git.
2) Copie todos os arquivos deste pacote para a RAIZ desse repositorio e substitua os existentes.
3) Confirme que index.html está na mesma pasta onde existe .git.
4) No terminal dessa pasta, rode:
   git status
   git add .
   git commit -m "Atualiza login e primeiro acesso do Climax Portal"
   git push origin main
5) No GitHub, confirme que index.html mudou no ultimo commit.
6) Aguarde o GitHub Pages publicar e atualize com Ctrl+F5.
